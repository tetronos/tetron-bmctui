tetron-bmctui

Your server's BMC in the terminal. Serial console, power control, sensors and event log in one window, from your desk or over SSH.

Download Source and docs

  • Console in a pane

    Serial over LAN with BIOS colors, scrollback and zoom.

  • Power while you watch

    Open the power menu over the console and see the server restart.

  • Many servers

    Add hosts in the program or in a plain list. Switch with a number key or a click.

  • Status at a glance

    Overview, sensors, event log and inventory, with filter and export.

  • Mouse or keyboard

    Click anything, or never touch the mouse. Works over SSH.

  • Careful by default

    Starts read-only, asks before dangerous actions and keeps an audit log.

The console stays at the center

Open serial over LAN in a pane and keep your server list and screens beside it. Zoom when you want the whole terminal.

Power cycle without looking away

The power menu opens on top of the console, which stays connected behind it. The menu names the server, so you know which one you are about to restart.

Check the hardware

Read sensors, events and inventory. Screens refresh when you ask, so a busy BMC is left alone; turn on Live to watch readings. Type / to filter and press e to save the screen to a file.

Get started

On Debian and Ubuntu, install from the tetronos apt repository. ipmitool comes with it:

sudo curl -fsSLo /usr/share/keyrings/tetronos-archive-keyring.gpg https://tetronos.github.io/apt/tetronos-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/tetronos.sources https://tetronos.github.io/apt/tetronos.sources
sudo apt update && sudo apt install tetron-bmctui

Or build from source with Rust 1.91 or newer. You also need ipmitool:

git clone https://github.com/tetronos/tetron-bmctui
cd tetron-bmctui
cargo build --release
target/release/tetron-bmctui -H 192.0.2.10 -U ADMIN --pass-file ~/.bmc-pass

The password file must have mode 0600. Binaries for x86_64 and aarch64 Linux are on the releases page. See the README for the host list, keys and options.

Early development. Written for Supermicro BMCs first and tested on hardware with one Supermicro H12 board. Not every action has been verified. It uses IPMI only, without Redfish or virtual media. Keep BMCs on a private network.
